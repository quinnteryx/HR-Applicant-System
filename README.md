# HR-Applicant-System
 a Windows-based HR Applicant Processing System that supports both applicant selfservice and HR recruitment operations. The application allows applicants to register, log in, input, edit, and submit their application, while allowing HR users to review, screen, schedule interviews, evaluate, and make final hiring decisions.
