## AI USAGE

During the development of my module, I used AI as a tool to help me when I got stuck on certain parts of my code. Instead of generating the entire code, I asked it specific questions about errors I was encountering and things I did not fully understand. It helped me figure out what was wrong and guided me on how to fix it. I also used it for things like comparing two lists from the database, preventing deletion of records under review, and pushing my local repository to the main group repository as a separate branch.

## The following are the actual prompts I used:

my save button has an unknown field name error how do i fix it

my column names in my code dont match the database how do i fix it

how do i stop delete if the document is under review

how do i load document types from the database into a combobox

why is my datagridview empty when the form loads

how do i find missing documents by comparing two lists from the database

why is my profile form showing errors after i made changes

how do i push my local repository to the main group repository as a separate branch

how do i push my commit to my own branch in the group repo

how do i show the interview schedule from the database in a label
